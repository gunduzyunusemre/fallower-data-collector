# Test Data Headers - STM32H7 AI Inference System

## Overview
This directory contains 70 C++ header files with normalized test data for AI inference testing.
Each file contains one test sample in the format expected by the X-CUBE-AI framework.

## Data Format
- **Original Shape:** (30, 688) - 30 frames × 688 features
- **Flattened Size:** 20,640 float32 elements (82,560 bytes)
- **Normalization:** Frame-wise scaling to [-1000, 1000] range
- **Memory Section:** .rodata (Flash memory allocation)

## Usage in STM32 Code

### Include Example:
```c
#include "data/walk_1622_test_data.h"

// Access test data
const float* test_input = walk_1622_test_data;
int data_size = walk_1622_test_data_size;        // 20640
int frame_count = walk_1622_test_data_frames;    // 30
int frame_size = walk_1622_test_data_frame_size; // 688
```

### Memory Usage:
- Each file: 82,560 bytes in Flash (.rodata section)
- Total Flash usage: ~5.78 MB for all 70 files
- Runtime RAM: No additional allocation (data stays in Flash)
